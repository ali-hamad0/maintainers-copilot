Maintainer's Copilot — Demo Host

This page simulates an external host site that embeds the Copilot widget. The widget is served from http://localhost:3000 and will appear in the bottom-right corner once it is allowed by the CORS origin allowlist stored in Postgres.

To test origin blocking: load this page from a host not in widget_config.allowed_origins and confirm the widget is blocked in the browser console.
